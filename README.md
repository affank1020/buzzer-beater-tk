# Buzzer Beater

A 2D basketball game built with Python and Tkinter for a university assignment. It has 15 levels across three locations, custom physics and collision detection, and saved progress.

![Buzzer Beater gameplay](https://github.com/user-attachments/assets/d1403acf-b941-45c4-a68e-c9da02317130)

## Features

- 15 levels across three locations
- Force-based ball movement, gravity, and collision detection implemented in Tkinter
- Multiple player profiles and save/load support
- Animated menus

## Controls

| Key | Action |
| --- | --- |
| A / D | Adjust shot angle |
| W / S | Adjust shot power |
| Space | Shoot |

## Run

1. Download the repository.
2. Keep `Buzzer Beater.exe`, `data.json`, and the `images/` folder together.
3. Run `Buzzer Beater.exe` on Windows.

The executable does not require a separate Python installation.
